# Texture sources

All five assets come from ambientCG, which states that all its assets are CC0 1.0 Universal (<https://docs.ambientcg.com/license/>, checked on 2026-11-07). Each asset page below also mentions CC0. CC0 needs no attribution; the list is here so each file can be traced. The legal text is at <https://creativecommons.org/publicdomain/zero/1.0/>.

| File | Source page | Download | Map used | Licence | What was done to it |
|---|---|---|---|---|---|
| `tex/ceramic-plaster.webp` | <https://ambientcg.com/view?id=Plaster001> | <https://ambientcg.com/get?file=Plaster001_1K-JPG.zip> | Color | CC0 | Greyscale, levelled, mapped to off-white, 1024 px |
| `tex/painted-metal.webp` | <https://ambientcg.com/view?id=PaintedMetal004> | <https://ambientcg.com/get?file=PaintedMetal004_1K-JPG.zip> | Color | CC0 | Greyscale, levelled, mapped to pale grey, 1024 px |
| `tex/metal-brushed.webp` | <https://ambientcg.com/view?id=Metal009> | <https://ambientcg.com/get?file=Metal009_1K-JPG.zip> | Color | CC0 | Greyscale, levelled, mapped to steel, 640 px |
| `tex/glass-scratched.webp` | <https://ambientcg.com/view?id=Scratches005> | <https://ambientcg.com/get?file=Scratches005_1K-JPG.zip> | Opacity | CC0 | Levelled so only the marks remain, 640 px |
| `tex/smudge-grime.webp` | <https://ambientcg.com/view?id=SurfaceImperfections013> | <https://ambientcg.com/get?file=SurfaceImperfections013_1K-JPG.zip> | Color | CC0 | Greyscale, levelled, 640 px |

Only the converted WebP of each download is included. No author is listed because ambientCG's API gave none for these assets.

Whether each asset is a scan or procedural was not checked. `ceramicPanel` and the other parts are drawn from code and lit with these textures.
