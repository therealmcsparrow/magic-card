## All keys

| UI label | YAML key | Values | Default |
| --- | --- | --- | --- |
| | `id` | A unique string | Generated by the editor |
| From | `from` | Module id of the start module | Required |
| To | `to` | Module id of the end module | Required |
| Entity | `entity` | An entity id | None: always flowing |
| Attribute | `attribute` | An attribute of the entity | The state |
| Min | `min` | Number, 0 or more | `0` |
| Max | `max` | Number | `1000` |
| Reverse when negative | `reverse_negative` | `true`, `false` | `true` |
| Route | `route` | `curve`, `straight`, `elbow` | `curve` |
| From side | `from_side` | `auto`, `top`, `right`, `bottom`, `left` | `auto` |
| To side | `to_side` | `auto`, `top`, `right`, `bottom`, `left` | `auto` |
| Color | `color` | Any CSS colour, `entity`, `entity N%` | The theme's primary colour |
| Idle color | `idle_color` | Any CSS colour, `entity`, or `N%` of `color` | Secondary text colour at 50% |
| Width (px) | `width` | 0.5 to 40 | `3` |
| Glow (px) | `glow` | 0 to 30 | `0` |
| Scale width | `scale_width` | `true`, `false` | `true` |
| Dots | `dots` | 0 to 8 | `3` |
| Dot size (px) | `dot_size` | 1 to 40 | `6` |
| Speed (s) | `speed` | Seconds, 0.2 or more | `2` |
| Min speed (s) | `min_speed` | Seconds, 0.2 or more | `8` |
| Label | `label` | `none`, `value`, `template` | `none` |
| Label template | `label_template` | Text or a Jinja template | |
| Label position | `label_position` | `auto`, `line`, `side`, `hidden` | `auto` |
| Show | `show_when` | `always`, `flowing` | `always` |
| Layer | `layer` | `back`, `front` | `back` |

Out-of-range numbers are limited to the range. An unknown value of a choice key uses its default.

## Ends and route

- `from` and `to` are module ids. Any module of the card can be an end, including modules inside layout modules.
- From side and To side pick the side of each module the line attaches to. Auto picks the pair of sides that face each other. On a shaped module the line meets the shape's outline on that side.
- Route:

| UI label | `route` | Line |
| --- | --- | --- |
| Curve | `curve` | A smooth curve |
| Straight | `straight` | A straight line |
| Elbow | `elbow` | Right angles with rounded corners |

## Value

- Entity is the value source. Without one the help line says "No entity: the line always flows at its speed."
- Attribute shows once the entity has attributes.
- Min: at or below this magnitude the line idles. A negative `min` counts as 0.
- Max: the magnitude where speed and width reach their maximum. With `max` at or below `min`, any value above `min` counts as the maximum.
- Reverse when negative: "A negative value runs the dots from the end to the start." Turn it off to ignore the sign.

## Colours

`color` is the colour of the line and the dots.

- `entity` uses the state colour of the flow's entity. A flow without an entity uses the From module's entity. `entity 40%` is that colour at 40% opacity. The swatch in the editor previews the same colour.
- An entity without a state colour (a sensor, for example) falls back to the theme's primary colour. See [Entity colours](../design/entity-colours.md) for which entities have one.

`idle_color` is the line's colour while it idles.

- `30%` (a percentage) means `color` at 30% opacity.
- A colour, or `entity`, works as for `color`.
- Unset: the theme's secondary text colour at 50% opacity, which reads on light and dark cards.

The editor offers the entity colour button on Color only. Type `entity` in Idle color to use it there.

## Width, dots and speed

- Width (px) is the line width. With Scale width on ("Up to twice the width at Max."), the line grows to twice the width at `max`.
- Glow (px) draws a soft glow around the dots.
- Dots is the number of dots on the line at once. `0` draws moving dashes instead ("0 dots: moving dashes instead."). Browsers that can't move dots along a path also get dashes.
- Dot size (px) is the dot diameter.
- Speed (s) and Min speed (s) are the seconds a dot takes to travel the whole line: Speed at `max` (and for a flow without an entity), Min speed just above `min`. Help line: "Seconds for a dot to travel the line: Speed at Max, Min speed just above Min."

## Label

A label sits at the middle of the line in a small pill with the line's colour as border.

| UI label | `label` | Shows |
| --- | --- | --- |
| None | `none` | No label |
| Value | `value` | The entity's value, formatted like Home Assistant (with its unit). Needs an entity: "Pick an entity: a value label needs one." |
| Template | `template` | `label_template`: plain text, or a Jinja template rendered by Home Assistant |

A Jinja label shows nothing until Home Assistant has rendered it.

Label position (shown while a label is set):

| UI label | `label_position` | Placement |
| --- | --- | --- |
| Auto | `auto` | On the line when it has room, else beside it. Beside means above a horizontal line or right of a vertical one, else the other side. A label that would cover a module, another label or the card's edge is hidden. |
| On the line | `line` | Always on the line |
| Beside the line | `side` | Always beside the line |
| Hidden | `hidden` | Not shown |

## Show and layer

| UI label | YAML key | Values |
| --- | --- | --- |
| Show | `show_when` | Always (`always`), While flowing (`flowing`: the line hides while it idles) |
| Layer | `layer` | Back (`back`), Front (`front`) |

### Layer

- `back` draws the line behind module content and over row and column backgrounds.
- `front` draws it over module content. It never blocks taps.

A back line also runs under a layout module's own background (a Horizontal or Vertical stack with a background) and under a Slider module. A row or column with animations, particle layers, a video background, a [shape](../design/shapes.md), a [value background](../design/value-backgrounds.md), or a filter, opacity, transform, clip or mask in its design is lifted above back lines, so its background covers them. Use `layer: front` for a flow that has to show over those.
