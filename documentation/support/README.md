# Support replies

Ready-made replies for the two questions that come up most. Copy the text under each heading.

## Pause reply

Did you press Pause? Press the Pause motion button on the card again to play it. The pause is remembered in this browser, so it stays after a reload. If the button does not show, saving any change to the card ends the pause, and so does clearing this site's data in the browser, which also signs you out of Home Assistant and resets its settings in that browser.

## Update reply

After an update, the card file and its parts can come from different releases. The card then shows a tile that says "Magic Card updated. Tap to reload." (the text of the key `card.chunk-notice.magic-card-updated-tap-to-reload`). Tap the tile once. The card asks for a fresh copy of its file and reloads the page, and the tile goes away. If the tile comes back and says "Still the old version. Clear the browser cache, then reload.", clear the cache, as described under [Clear the browser cache](../loading-and-size/README.md#clear-the-browser-cache). In a browser, clear the cached images and files for this site, then reload. On a wall tablet or in the Home Assistant app, open the app settings, go to Debugging, choose Reset frontend cache, then reopen the dashboard.
