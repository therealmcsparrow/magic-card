# Support replies

Ready-made replies for the two questions that come up most. Copy the text under each heading.

## Pause reply

Did you press Pause? Press the Pause motion button on the card again to play it. The pause is remembered in this browser, so it stays after a reload. If the button does not show, saving any change to the card ends the pause, and so does clearing this site's data in the browser, which also signs you out of Home Assistant and resets its settings in that browser.

## Update reply

After an update, the card file and its parts can come from different releases. The card then shows "Magic Card was updated. Reload the page to see this part. The rest of this card works." (the text of the key `card.chunk-notice.magic-card-was-updated-reload-the-page`). Press **Reload page**, or hard refresh the browser, and the notice goes away.
