# YAML examples

Complete cards you can paste into the code editor and adapt. Replace the entity ids with your own. Every key used is described in the [schema](../schema.md).

| Example | Shows |
| --- | --- |
| [Entity tile](entity-tile.md) | One switch: entity-coloured icon, name and state, tap to toggle, hold for more-info |
| [Light control](light-control.md) | Power button with a morphing icon, brightness slider, colour and effect controls |
| [Energy flow](energy-flow.md) | Solar, grid, house and battery with animated flow lines driven by power sensors |
| [Weather and clock header](weather-clock-header.md) | Clock with date, current weather and a five-day forecast |
| [Tabs with nested layouts](tabs-nested.md) | Tabs holding a horizontal stack, a two-column row with a gauge, and a vertical list |
| [Conditional visibility and styling](conditional-visibility.md) | Card, row and module display conditions, a conditional design rule, conditional appearance |
| [Pop-up card](popup.md) | A dialog opened by a button, a `#hash` link or a doorbell sensor |
| [Animations and rings](animations-ring.md) | Icon animation on state, a tap animation, a value ring with thresholds, an animated card ring |
| [Liquid-fill icons](liquid-fill.md) | Fill by value, value-coloured gradient, duotone, device animation, line draw |
| [Template-linked card](template-linked.md) | A shared template and a linked card that overrides entities and background, and changes or hides the template's animations |
| [Jinja templates](jinja-templates.md) | Templated text, markdown with an entity variable, a template condition, a flow label |
| [Shaped card with a value background](shaped-value-background.md) | A squircle card filled to a tank level, a hexagon tile with a history sparkline, column widths |
| [Seasonal scene](seasonal-scene.md) | A date-driven scene with day and night, an off switch, own holiday dates, a seasonal preset on one button |

The shorter examples in the [main README](../../../README.md#yaml-examples) cover a single feature each.
