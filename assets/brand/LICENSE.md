## Rigs cut from Material Design Icons

The rig files in `icon-library/` are built from icon shapes of [Material Design Icons](https://pictogrammers.com/library/mdi/), maintained by Pictogrammers and taken from the `@mdi/js` package. Each shape was split into separate pieces so that parts can move on their own. The rigs are modified versions of the original shapes, and this note states that change as the Apache License 2.0 asks.

The Material Design Icons shapes in those files stay under the [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0). If you copy or share a rig, or a piece of one, keep this note with it. That keeps the Apache License 2.0 attribution to Pictogrammers and the pointer to the licence text with the shapes. The package ships no NOTICE file. The licence statement from the package and the full licence text are in [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md), and the README credits the same source.

Pictogrammers does not endorse Magic Card, and the Material Design Icons name is used only to say where the shapes come from.
